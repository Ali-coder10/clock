# Global Time Tracker

A premium, modern, and highly customizable Clock & Time Zone Web Application designed for traders and global time users. Features real-time clocks, trading session tracking, and bidirectional timezone conversion with elegant glassmorphism design.

## Features

- **Real-time Clocks**
  - UTC clock
  - Local time (auto-detected)
  - London time
  - New York time
  - Tokyo time
  - Updates every second

- **Multiple Clock Themes**
  - Modern Digital Clock (LED/neon style)
  - Luxury Analog Clock (watch-inspired)
  - Vintage Clock (Roman numerals, antique style)
  - Glass Clock (frosted glass effect)
  - Trading Clock (subtle trading theme)

- **Dynamic Backgrounds**
  - Pure Black Minimal
  - Gradient Dark
  - Night Sky
  - City Lights
  - Forex Candlestick Background
  - Luxury Texture
  - Vintage Texture
  - Futuristic Neon

- **Trading Session Tracker**
  - London, New York, and Tokyo sessions
  - Real-time Open/Closed status with glowing indicators
  - Live countdowns to next open/close

- **Bidirectional Time Converter**
  - Convert between local time and major timezones
  - Live UTC offset display
  - Instant conversion results

- **Customization & Persistence**
  - 12h/24h format toggle
  - Theme and background selection
  - Animation preferences
  - Automatic saving to localStorage

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Grid, Flexbox, CSS Variables
- **Icons**: SVG icons
- **Fonts**: Google Fonts (Inter)
- **No external dependencies** - pure vanilla JS
